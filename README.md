# Trimerge Pro Careers Monorepo

This repository is organized as a modern monorepo for a professional web application project. It is structured for scalability, maintainability, and team collaboration.

## Structure

- `apps/web` — Main web frontend application
- `apps/api` — Backend API service
- `packages/shared` — Shared code and utilities (TypeScript, Python, etc.)
- `docs` — Project documentation

## Getting Started

1. Clone the repository
2. Install dependencies for each app/package as needed
3. Follow documentation in the `docs` folder for setup and contribution guidelines

## Contributing

- Keep code modular and DRY
- Use the `packages/shared` folder for code reused across apps
- Document changes in the `docs` folder
